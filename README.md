# Wichi

Descargas de Wichi, el asistente de IA (OpenCode + NVIDIA NIM):

- **AI-Mobile.apk**: la app para Android.
- **Wichi-win-x64.zip**: la app para PC con Windows (trae su propio .NET; abre `Wichi.cmd`).

Las apps buscan aquí las versiones nuevas desde Ajustes → Actualizaciones. Ver la pestaña **Releases**.
